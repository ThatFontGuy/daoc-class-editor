Welcome to Othlyn II server running Divided Realms

Othlyn is a private Dark Age of Camelot server running the Divided Realms linux port of the original Divided Realms. Its running on a desktop server beside the main computer of ThatFontGuy who has been streaming it on Twitch. The primary purpose of this server has been to let me explore how the internals of the game work and to enable me to create a Class Editor to create my own classes. Thus this server has several classes that have not been seen elsewhere. Its enormous fun.

Unique to this server:

This iteration of the Divided Realms server features the use of my Class Editor for DAOC, (being developed as a separate Github project) which allows me to create my own DAOC classes to experiment with Class designs of my own creation. The editor, when complete, will allow you to clone existing classes, adjust what spec and spell lines they can train in, edit the spells, remove spells and add spells to those lines and even create an entirely new spell line to use with your new characters using existing spells and specs that are already in the game but in other classes. Its pretty flexible so far but I am still testing the results to see if there are any bugs (hint: there will be). It also auto generates a Charplanner web tool that you can post on a website that reflects exactly the character classes, spells and spec lines that are in operation on your version of the game. This should work with any Dawn of Light related version of the server software but I am testing it against the Divided Realms version specifically. It shoudl work with both the Linux and Windows version of the Divided Realms server software as well. Still a WIP at this point.

This version of the server software is set to NOT allow autocreation of accounts, so access to the server is by invitation only. Accounts must be create manually by the GM. Sorry but I don't want the box to catch fire if an onslaught of new users attempted to access it.

Use the Character Planner to plan out a character's specializations before you ever log in, or the Get Started page for install instructions.
