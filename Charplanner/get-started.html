Before you start

  • You will need a copy of the official Dark Age of Camelot install, patched to the 1.130 client version.
  • Windows feature .NET Framework 3.5 turned on (Control Panel → Programs → Turn Windows features on or off).
  • The whole thing takes about 6 GB free disk space (during setup a copy of your DAoC client is made; your original install is never changed).

How to play

  1. Extract the zip somewhere, e.g. C:\DividedRealms.
  2. Run 1 - SETUP (run once).cmd. Pick your DAoC folder when asked — this patches a copy, not your original install. Do this once.
  3. Open 2 - Connect.cmd in Notepad, set ACCOUNT and GAMEPASS to whatever your username and password are set to, save it.
  4. Double-click 2 - Connect.cmd to play.

Full instructions are in README.txt inside the zip.

Planning your character

Before you commit spec points in game, try the Character Planner to see every class's real specializations, spells, styles, and Realm Abilities, and plan out a build level by level.
